#WebMandiriDAMP

Sebuah website blog modern untuk semua orang. Mulai dari cerita ringan hingga pembahasan-pembahasan yang lebih serius, YourBlog akan menyediakanmu berbagai topik yang mungkin kamu suka. Dengan tampilan sederhana dengan kesan modern tentunya membuat website ini menarik untuk dikunjungi.

Fitur Utama
- Home Page
- Featured Articles
- Categories
- Search Feature
- Newsletter
- Responsive Design

Implementasi UI
- Menggunakan kombinasi warna biru, putih, dan abu-abu yang memberikan kesan profesional dan modern
- Menggunakan font Poppins dan DM Serif Display untuk meningkatkan keterbacaan dan estetika
- Menggunakan layout berbasis Grid dan Flexbox agar tampilan lebih rapi
- Menerapkan Card Design untuk artikel dan kategori

Implementasi UX
- Mengutamakan website responsif agar nyaman digunakan
- Readability website yang baik agar mudah digunaka
- Navigasi Website yang jelas

Teknologi Dalam Website
- HTML : struktur halaman website
- CSS : desain tampilan website
- JavaScript : fungsi interaktif website
- Google Fonts : tipografi
- CSS Grid : layout yang responsif
- Flexbox : mengatur elemen-elemen halaman website
